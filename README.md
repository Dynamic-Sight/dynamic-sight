# Dynamic-Sight · German electricity price forecast (free tier)

Live page: https://ouabo.github.io/dynamic-sight/

Day-ahead price forecasts for Germany-Luxembourg, submitted to the independent
[Energy Arena](https://energy-arena.org) platform before every auction (participant **Dynamic-Sight**),
shown here only after the auction result is published.

This repository holds only the published page and its data. Model code is not public.
Updated daily.

- Prices: Bundesnetzagentur | SMARD.de (CC BY 4.0)
- Ranks: Energy Arena public leaderboard
- Not investment advice.
