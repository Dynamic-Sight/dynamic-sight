# Dynamic-Sight · electricity forecasts (free beta)

Live page: https://dynamic-sight.github.io/dynamic-sight/

Forecasts for Germany-Luxembourg, submitted to the independent [Energy Arena](https://energy-arena.org) platform
(participant **Dynamic-Sight**):
- day-ahead prices;
- total load;
- solar generation.

Tomorrow's forecasts are shown once each gate has closed: prices after 12:00, load and solar after 18:00.

Spain day-ahead prices are a shadow model and are not submitted.

Everything is free during the beta.

This repository holds only the published page and its data. Model code is not public.
Updated daily.

- DE prices: Bundesnetzagentur | SMARD.de (CC BY 4.0)
- Spain prices: ENTSO-E Transparency Platform (data: OMIE)
- Ranks: Energy Arena public leaderboard
- Not investment advice.
